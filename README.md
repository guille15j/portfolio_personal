# Portafolio de Guillermo Santos Sánchez

Este repositorio contiene el código fuente de mi portafolio profesional como desarrollador backend y técnico de sistemas. El sitio está diseñado bajo la filosofía de "Rigor de proceso, velocidad de producto".

## 🌐 Enlace en Vivo
Puedes ver el proyecto funcionando en línea aquí:
👉 **[Ver Portafolio en Vivo](https://portfolio-personal-black-ten.vercel.app/)**

## 🚀 Objetivo del Proyecto
Presentar de manera visual y técnica mis capacidades en el desarrollo de software y mi experiencia en gestión de proyectos. El sitio utiliza una identidad visual propia inspirada en conceptos de telemetría y diseño industrial.

## 🛠 Tecnologías Utilizadas

La arquitectura del front-end utiliza un sistema **utility-first** para garantizar mantenibilidad y rendimiento óptimo:

*   **Styling:** [Tailwind CSS](https://tailwindcss.com/)
*   **Lenguajes:** HTML5, JavaScript (ES6+).
*   **Build Tools:** Tailwind.
*   **Integraciones:** EmailJS (para el funcionamiento del formulario de contacto).
